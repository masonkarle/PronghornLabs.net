# Switchback

**Scripture citations, stamped onto the ASL note-taking worksheet.**

Switchback stamps each paragraph’s scripture citations onto the blank ASL note-taking worksheet, so someone watching the ASL video can take notes without hunting for references. For Mac, iPad and iPhone. Free and works offline.

### How it works
1. **Get the files.** A checklist links to each file’s jw.org page: the ASL worksheet (PDF), the ASL publication (JWPUB) and, optionally, the English PDF, which tells Switchback which scriptures are the “Read” ones.
2. **Add them.** Drop them on the window or the Dock icon, or use Choose Files… (⌘O), in any order. Files are recognised by their contents, not their names, and a wrong issue, edition or language is refused with the name of the file to get instead.
3. **Fill the worksheet.** Review the stamped preview with its report beside it, and make light edits: mark a citation as “Read” (bold), move it, delete it, or place one that had nowhere to go.
